о чём

Сайт дизайн-студии — редкий случай, когда автор контролирует всё: какой кейс встретит посетителя, каким цветом и в каком порядке. Но всё реже этот сайт видят таким, каким его задумали. Студию находят в телефоне, где экран вчетверо меньше. Её присылают ссылкой, и вместо первого экрана человек получает карточку, которую мессенджер собрал из нескольких строк кода.

Исследование называет этот процесс деавторизацией: сайт остаётся, но решения о том, как его увидят, принимаются уже не в студии.

Ключевой вопрос: остаётся ли дизайн-студия автором своего изображения, когда её сайт видят не целиком и не на большом экране?

Гипотеза: чем дальше изображение студии уходит от её сайта, тем меньше в нём авторских решений. Три условия — три главы:

  1. заходи — первый экран на десктопе. «Своего мало даже на десктопе» — не подтвердилось: своего больше половины экрана у 12 студий из 20.
  2. листай — тот же экран на телефоне. «Студии становятся похожи друг на друга» — подтвердилось: разброс палитр падает со 100 до 77.
  3. делись — карточка ссылки в мессенджере. «От студии остаётся только то, что она прописала в коде» — подтвердилось: ни одна карточка не показывает работу студии.

24% > 18% > 0%

медиана доли цветного: сайт на десктопе > сайт на телефоне > картинка карточки ссылки

протокол

Все двадцать сайтов сняты одним скриптом в один день — 11.11.2026. Снималась только главная страница.

  • десктоп — окно 1440 × 900, снимок в 2×;
  • телефон — окно 390 × 844, как у iPhone 13, снимок в 3×;
  • съёмка начинается через 3 секунды после загрузки;
  • 10 кадров, ровно по одному в секунду;
  • плашки куки, окна чатов и другие всплывающие элементы не закрываются: их видит каждый новый посетитель.

Почему десять секунд: в первые секунды визита вероятность ухода со страницы выше всего; если человек остался после десяти, скорее всего, он задержится надолго (Nielsen, 2011).

доля кадра
Первый экран делится сеткой: 20 × 12 клеток на десктопе, 10 × 22 на телефоне. Каждая клетка размечается вручную как «своё» (работа, текст и знак студии), «чужое» (плашки куки, виджеты, элементы платформ) или «пустота».
цвет
Кадры 2–10 переводятся в OKLab. Пиксели с цветностью ниже 0,045 считаются нейтральными. Для каждой студии считаются доля цветного и палитра из трёх нейтральных и четырёх цветных тонов. Разброс палитр — среднее расстояние между палитрами всех пар студий; десктоп принят за 100.
карточка ссылки
Из кода главной страницы берутся og:image, og:title и og:description. Где тега нет, берётся то, что подставит мессенджер: заголовок вкладки и meta description. Карточки в книге — реконструкция по коду, а не скриншоты из мессенджеров.

код

Всё лежит в репозитории github.com/rdnve/nobody-visual-research.

capture.pyсъёмка: скриншоты, 10 кадров, раскадровки, код страницы, теги карточки, тип движения
color.pyцвет по одиночным скриншотам: доля цветного, палитры, разброс
color9.pyцвет по кадрам 2–10 — эти числа стоят в книге; палитры в SVG, PDF, PNG
studios.csvсписок студий: номер, имя, адрес, страна, основание отбора

установка — один раз, нужны Python 3.12 и poetry 1.8.5:

$ poetry install
$ poetry run playwright install chromium
$ poetry shell

съёмка:

# все студии из studios.csv
$ python capture.py

# только 01 и 08                       
$ python capture.py --only 01,08          

# с видимым окном браузера
$ python capture.py --headed              

# доснять папку прошлого дня
$ python capture.py --out capture-2026-11-11

# без прокси
$ python capture.py --proxy none

Скрипт создаёт папку с датой съёмки. Уже снятые студии повторно не снимаются, так что прерванную съёмку можно просто запустить снова. Двадцать студий снимаются за 15–25 минут. --headed нужен, если вместо сайта пустая страница или «проверка браузера». По умолчанию прокси берётся из настроек macOS; пароль прокси не печатается и не попадает в таблицу.

цвет:

# по кадрам 2–10, как в книге
$ python color9.py capture-2026-11-11     

# по одиночным скриншотам
$ python color.py capture-2026-11-11

что получится:

  frames/        по 10 кадров десктопа и телефона

  data.csv       одна строка на студию, разделитель — точка с запятой

  palettes9/     палитры в SVG, PDF и PNG

Скриншоты сайтов в репозиторий не выложены: это чужие изображения. Их можно получить заново тем же скриптом — но сайты меняются, и результат будет уже другим.

данные

  • data/svodka.csv — все числа книги: своё, чужое и пустота на десктопе и телефоне, доля цветного на десктопе, телефоне и в карточке, теги карточки;
  • data/capture-data.csv — полная таблица съёмки: теги, заголовки, движение, robots.txt и прочее.

ограничения

  • Двадцать студий — не статистика, а ряд для сравнения: выводы показывают тенденцию, а не закон.
  • Сайты сняты один раз. Первый экран Depot и Студии Лебедева меняется при каждом заходе, у Limb и PG Branding сначала показывается заставка загрузки. Lokals из России не открывается и снят через прокси.
  • Окно телефона — 390 × 844 по протоколу. В настоящем браузере часть экрана занимает адресная строка.
